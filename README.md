### 2. Woodwork Service Platform

**Duration:** February 2025 – May 2025

A platform for managing woodwork services, including user accounts, service bookings, order processing, and schedule management.

- **Tech Stack:** Java, Spring Boot, MySQL, RESTful APIs, React.js, React Native, Google Cloud, Railway
- **Backend Repository:** [WDCRBP API](https://github.com/Phuc-TV/SP25SE026_GSP48_WDCRBP_API)
- **Web Frontend Repository:** [WDCRBP Web App](https://github.com/votrongluan/SP25SE026_GSP48_WDCRBP_WebApp)
- **Mobile Repository:** [WDCRBP Mobile App](https://github.com/leanguyen2619/SP25SE026_GSP48_WDCRBP_Mobile)
- **Documentation Repository:** [Project Documentation](https://github.com/namyus/all-project-docs)
- **Final Report (PDF):** [WDCRBP Final Report](https://github.com/votrongluan/SP25SE026_GSP48_WDCRBP_WebApp/blob/main/doc/WDCRBP_Final_Report.pdf)
- **Reports and Diagrams:** [Documentation Folder](https://github.com/votrongluan/SP25SE026_GSP48_WDCRBP_WebApp/tree/main/doc)

**Key Contributions**
- Developed backend APIs for user management, service booking, order processing, and schedule management.
- Implemented JWT authentication and OTP verification using Twilio/Gmail.
- Integrated the Giao Hang Nhanh (GHN) API for delivery tracking.
- Deployed backend services to Google Cloud, with MySQL hosted on Railway.
